Eloquent query basics

Schema::hasTable('products')Check if a table exists.
Schema::getColumnListing('products')List a table's column names.
Product::limit(5)->get()Get 5 records.
Product::latest()->take(10)->get()Get the 10 newest records.
Product::all()Get every row — quick check that the table has data.
Product::count()Row count.
$movements = StockMovement::with(['product.category', 'user'])->get()Fetch related models along with the main model.
->when($search, function ($query) use ($search) {$query->where('name', 'like', "%{$search}%");})Search for rows matching a pattern condition.
Product::first()->nameGet just the first row's name.
Product::where('name','Mouse')->first()Find by a column value. first() returns one model, get() returns a collection (list) even if there's one match.
Product::find(1)Find by primary key.
Product::findOrFail($id)Same as find() but throws a 404 error automatically if not found — used before update/delete.
Product::pluck('id')Get a flat list of one column's values.
Product::select('id','name')->get()Only fetch specific columns.
firstOrCreate([...])Find the first matching row, or create it if none exists.
firstWhere('id', $id)Shortcut for where(...)->first() — one matching row.
$orders = Order::whereBetween('created_at', ['2023-01-01', '2023-12-31'])->get()Find rows within a date range.
where('status', 'active')Find rows where the column equals a specific value true.
whereNull('col')find Rows where the column is empty/null.
whereNotNull('col')Find rows where the column is not empty/null.
whereDate('created_at', '2023-01-01')Find rows where the date portion of a datetime column matches.
whereIn('id', [1,2,3])Match against multiple values at once (vs. where() for a single value).
whereHas('category', ...)Filter rows based on a condition forign_key on a related other table.
::where('status', 'active')->orWhere('has_uom', false)Find rows where the column matches or another condition.
OrderItem::whereColumn('quantity', '>', 'available_quantity')->get();Find rows where two columns have the same value.
orderBy('name')Sort ascending/descending by a column.
->latest()Shortcut for orderBy('created_at','desc').
distinct()Remove duplicate rows/values, keeping only unique ones.
pluck('name')Get a flat list of one column's values.
get()Actually runs the query and returns the results as a collection.
->values()Re-index a collection/array back to 0,1,2… after filtering leaves gaps.
->toArray()Convert a Collection into a plain PHP array (e.g. for JSON output).
->fresh()Re-fetch the current model's latest data from the DB.
truncate()Delete every row in a table (structure stays).

Relationships

belongsTo()This model holds the foreign key — e.g. a Product belongs to one Category.
hasOne()The other model has exactly one match — e.g. an Order hasOne Payment.
hasMany()The other model has many matches — e.g. a Category hasMany Products.
Primary key: the column that uniquely identifies a row in its own table (no two rows share it). Foreign key: a column that stores another table's primary key, used to link rows across tables. A pivot table is an extra table used to connect two tables in a many-to-many relationship.

PHP helper functions

abs()Always returns a positive number.
substr("Intel Core i9", 0, 3)Cut a piece of a string by position/length → "Int".
intval("10")Convert a string to an integer.
str_pad("10", 5, "0", STR_PAD_LEFT)Pad a string to a fixed length → "00010".
round()Round a decimal to a given precision.
ucfirst()Capitalize just the first letter of a string.
implode(', ', $array)Glue an array of strings into one string, joined by a separator. (This is the PHP equivalent of what your notes labeled "join" — see the SQL JOIN note below, they're unrelated concepts.)
collect($array)Upgrade a plain array into a Laravel Collection, unlocking methods like map(), filter().

Laravel extras

selectRaw()Write raw SQL math/expressions directly in a query.
whereColumn('a','=','b')Compare two columns to each other, Laravel style.
whereRaw('a = b')Same comparison, written as raw SQL.
withSum('items','total')Total sum of a related column, per row.
groupBy('date')Bucket rows into groups sharing the same value.
CarbonPHP library for working with dates/times.
CacheTemporary storage — e.g. "is this user active right now?"
session()Temporary per-user storage that persists across requests (e.g. cart, flash messages).
old('phone')Re-fill a form field with the previously submitted value after validation fails.
Auth::check()Is a user currently logged in?
redirect()Send the browser to another route/URL.
DB::beginTransaction()Group multiple DB writes so they all succeed or all roll back together.

Raw MySQL

USE blue_pos;                          -- select the database

SELECT * FROM products;                -- all columns

SELECT id, name, selling_price, stock_quantity
FROM products;                         -- specific columns

SELECT id, name, status
FROM products
WHERE status = "active";               -- filter by condition

SELECT * FROM products WHERE has_uom = 0;   -- exclude uom products

SELECT * FROM orders LIMIT 5;

-- JOIN: combine rows from two tables using a matching column
SELECT orders.order_number, users.name
FROM orders
JOIN users ON orders.cashier_id = users.id;

-- GROUP BY: collapse many rows sharing a value into one, so
-- aggregate functions (SUM, COUNT) can total each group separately
SELECT orders.order_number, SUM(order_items.total) AS subtotal
FROM orders
JOIN order_items ON order_items.order_id = orders.id
GROUP BY orders.id;

-- fuller example: multiple joins + GROUP_CONCAT to merge text values
SELECT
    orders.order_number,
    users.name,
    customers.name,
    SUM(order_items.total) AS subtotal,
    COUNT(order_items.id) AS item,
    orders.status,
    GROUP_CONCAT(order_items.name SEPARATOR ', ') AS products
FROM orders
JOIN users ON orders.cashier_id = users.id
JOIN customers ON orders.customer_id = customers.id
JOIN order_items ON order_items.order_id = orders.id
WHERE orders.status = 'refunded'
GROUP BY orders.id, orders.order_number
LIMIT 5;

SQL JOIN vs. array join()/implode(): SQL JOIN combines rows from two tables by matching a column. PHP's implode() (and JS's .join()) glue items of an array into one string. Same word, unrelated jobs — worth keeping separate in your notes.

JS async basics

awaitPauses inside an async function until a Promise (e.g. a fetch) resolves.
JSON.stringify()Convert a JS object/array into a JSON string to send over a network request.
